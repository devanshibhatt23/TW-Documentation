## Source note
The PDFs supplied for this work were **Doxygen.pdf** and **Git.pdf**. The Doxygen and Google Docs pages, and the Git and GitHub pages, follow those lecture slides. The Doxygen slides mention that LaTeX fundamentals had been taught earlier, but a separate LaTeX or Beamer slide deck was not supplied. Those two pages are therefore introductory notes based on common LaTeX usage, not a reconstruction of unseen lecture slides. Please compare them with your own class notes and add any instructor-specific commands.
